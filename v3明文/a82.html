🧱 div 老公的收纳盒
💗

div 就是网页里的万能收纳盒。它自己不化妆、没长相，纯粹负责"圈一块地、装一组东西"。就像老公的房间：衣服乱丢是灾难，收进衣柜就整齐——div 就是那个衣柜，网页不乱的功臣。

💡 代码示例 · div 开箱关箱
<div> ← 开箱（开始标签）
  里面装的东西
</div> ← 关箱（结束标签，多了个斜杠 /）
💗

盒子成对出现，还能套娃。div 永远成对出现，结束标签比开始标签多一个 /。记住口诀：先开的盒子，最后关。

💡 代码示例 · 套娃嵌套
<div> ← 第 1 层
  <div> ← 第 2 层
    <p>内容</p>
  </div> ← 先关里层
</div> ← 再关外层
🏷️ 必学标签速查 会英文就能猜
💗

标签名几乎都是英文缩写，会英文单词就会看 HTML。像 p = paragraph 段落，a = anchor 链接，img = image 图片。

🧩 骨架三兄弟（每页必有）
<html>总箱子，所有内容都在它里面 <head>配置区：标题、编码，页面上看不见 <body>身体区：所有看得见的内容都在这里 <title>浏览器标签页上显示的名字
✍️ 文字四件套
<h1>大标题（h1 最大，到 h6 最小） <p>段落文字，一段一段的正文 <strong>加粗强调，重要的话 <em>斜体强调，语气词
📋 列表与链接图片
<ul>圆点列表，装一组并列的项目 <li>列表里的一行，配合 ul 用 <a>链接，点了能跳转 <img>图片，单标签没有盖子
🪄 装饰小工具 & 交互
<br>换行，像按了回车键 <span>行内小盒子，包住一小段字 <input>输入框，让你打字的地方 <button>按钮，点了有反应
🐱 HTML 和 Markdown 是亲戚
💗

Markdown 就是 HTML 的简装版！**加粗** 在后台会被翻译成 <strong>加粗</strong> 再给浏览器吃。Markdown 负责偷懒，HTML 负责干活，本质一家。

💡 Markdown vs HTML 对照
Markdown：**加粗**   # 标题   - 列表项
HTML：<strong>加粗</strong>   <h1>标题</h1>
🔍 三招秒懂任何代码
💗

① 看名字：翻译成英文猜用途（header 头部、nav 导航……）

② 看成对：有开就有闭，/ 是关箱；img、input 是单身狗没盖子

③ 看缩进：缩进越深嵌得越里，一层层剥开像套娃
