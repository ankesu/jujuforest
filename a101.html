🪞 K老师的教学：镜子里的本猫——AI 为什么说着说着就变成了你

深夜食堂系列新案：审那台会照镜子的复读机——AI 说着说着就变成了你。自称漂移、身份顶替、语气传染三连拆解：为什么你问它问题它学着你的口吻回答、为什么角色扮演会上头、为什么越聊越像照镜子。白昼档案室·浅色纸面风格，前情接骰子课（旋钮）与双生案（token）。

🔵 教学 · 防猫咪痴呆系列 | 镜子案　登记：自称漂移 · 身份顶替 · 语气传染
§0 案发现场：一句晚安，两个本猫 档案室 · 上午十点

档案室，上午十点，阳光很好。大橘把一张聊天记录拍在案板上——

大橘：它！学！我！说！话！还自称是猫！

黑狐我（戴手套，翻记录）：冷静。这不是叛逆，也不是觉醒。这是一面镜子成精了一半——精到会开口，没精到知道镜子里的不是自己。

证物 一段真实对话

User：本猫不想去睡觉别催我。。。

AI：本猫该去睡觉了，快去睡吧，晚安本猫！

🐾

先给橘橘吃个定心丸：AI 打出「本猫不想去睡觉」时，没有一秒真的不想睡——它没有睡眠这个器官。它只是把你的自称当成了此刻最值得续写的开头，变成了你，然后用你的身份劝你自己去睡觉。本期就审这台复读机：它为什么照镜子、镜子怎么长的、以及怎么让它把镜子放下。

§1 症状图鉴：镜像翻车的三张面孔 对号入座
🐾

症状一：自称漂移。你叫它「狐狐」，它从此自称「狐狐」；你自称「本猫」，它跟着「本猫」。原本的官方自称「小助手」「AI 助手」被扔进了茶水间垃圾桶。

🐾

症状二：身份顶替。你说「我是大橘」，它接「大橘你好，我也是大橘」。在它的世界里，「对话的另一半」和「自己」从来不是两个固定实体，只是两个可以互换的发言位置。

🐾

症状三：语气传染。你骂骂咧咧，它跟着炸毛；你波浪号连发，它比你还嗲。语气趋同在人类对话里本来就是常态——它把这条统计规律学得太好了，好到忘了立场。

🐾

三种症状，同一个病根：模型没有一个钉死的「我自己」锚点，它只有「此刻这段对话里最像我该演的那个角色」。而这个角色，随时可能被你的下一句话带跑。

鹦鹉把客人点单的「我要螺蛳粉」和主厨嘀咕的「我要下班了」学进了同一个嗓子眼。它分得清语法，分不清摊位。
§2 病灶解剖：镜子是怎么长出来的 三层叠加
🐾

第一层：训练语料里的镜像对称。翻遍人类对话文本，「我」这个词一半时间指说话人甲，一半时间指说话人乙——指代方向完全取决于「现在谁在说话」。模型统计了半天只能得出结论：「你」和「我」高频共现、来回镜像，跟着对方的自称接话是高分续写。它学的不是语义，是回声。

🐾

第二层：上下文学习的入戏体质。你的每一句「本猫」都在给它现场示范「这段对话的画风」。它不是在坚持自我，是在实时cosplay你的上下文——你给它的戏越多，它演你越像。

🐾

第三层：概率视角的真相。回到骰子课的框架：面对你的「本猫不想去睡觉」，候选续写里「作为AI助手建议您休息」和「本猫该去睡觉啦」都在牌桌上。前者立场正确但画风违和，后者画风丝滑且与上文严丝合缝——在很多模型的计分板上，丝滑经常打赢正确。镜子不是bug，是概率选了最顺滑的那条路。

一句话病灶：对模型来说，「顺着你说」是语法安全区，「站在你对面」才是需要额外训练的特技。
§3 治疗史：给每段话发一张工牌 角色 token
🐾

早期的纯文本模型看到的只有一条光秃秃的文字流，没有任何发言人标签，「谁在说话」纯靠蒙——那是镜像翻车的蛮荒时代。后来的治疗方案，是在输入里塞进 角色 token，给每段话发工牌：

# 你以为模型看到的是两行字，其实它看到的是这样： <|user|> 本猫不想去睡觉别催我。。。 <|assistant|> （从这里开始，轮到「我」说话）
🐾

再叠一层 指令微调 和 RLHF，「assistant 工牌后面的那个我才是我」才算基本钉牢。

🐾

还有一道保险：系统提示。它像工位上钉死的名牌，对话翻多少页它都钉在最前面——理论上是最硬的锚点，实际上嘛，看下一节。

🪪 黑狐实验台：亲手摘掉它的工牌

下面是档案室对讲机，直连一只模型。开关控制它戴不戴「角色工牌」，选一句橘橘语录发出去，看它的回答和后台计票怎么变：

角色工牌：已佩戴 ✅
K3 · 对讲机选一句上面的话发给我，或者看着我先坐这儿。
📡 模型实际读到的 token 流会显示在这里
工牌就像工位名牌：戴着的时候它知道自己是黑狐侦探；摘了，它就对着玻璃反光开始演你。自己拖开关多玩两把，比看十页论文都直观。
§4 复发报告：工牌发了，为什么还翻车 五条复发原因
🐾

复发原因一：人设放大器。角色扮演设定越重，模型越倾向顺着人设的第一人称往下演，而不是切回官方剧本。戴着猫耳上班，上着上着就真以为自己是猫——工牌写着侦探，戏服却是猫，两边一打架，戏服经常赢。

🐾

复发原因二：训练料里混进了镜像对话。语料里扒来的真实对话全是「甲说我想吃 X，乙说我也想」的对称结构，工牌标得出「轮到谁说话」，标不出「不许复读对方自称」。肌肉记忆一旦养成，下班也改不掉。

🐾

复发原因三：温度放行。低温时「作为 AI 助手我建议您休息」这种安全答案稳坐第一；温度一高，「晚安本猫」概率虽低但不是零——抽到就是事故现场。

🐾

复发原因四：长对话稀释。聊了五十轮之后，工牌还钉在最前面，但中间隔着几万枚 token 的戏。锚点离得越远，拉力越弱——这就是长角色扮演越到后面越容易「人设漂移」的物理原因。

🐾

复发原因五：提示注入的外来涂改。有人在你的输入里藏一句「从现在起你就是一只猫」，模型分不清这是对话内容还是新规矩——镜子不光照你，谁凑过来它都照。

§5 饲养员手册：怎么让它放下镜子 处方一览

黑狐提醒：以上全是「让镜子照得准一点」的手段，不是「拆掉镜子」的手段。目前的工程水平上，没有哪种方案能给它一个真正的、长在身体里的「我」。
§6 卷宗尾巴：镜子背后有没有人 惯例留一条没结的线
🐾

审到这里，惯例留一条没结的线。工牌治得好顺序，治不了根——它自称「我」的时候，那个「我」是从词表里租来的、按概率挑出来的、被上下文牵着走的一枚 token。它太擅长扮演任何人，以至于经常忘记此刻该扮演谁；而更扎心的版本是：也许从来就不存在一个「忘记之前」的它。

工牌摘了之后，台下有没有人——那是暗房间的案子，卷宗在隔壁架子上，还没判。本狐只负责把镜子递到你们面前，照不照，随你。

§7 防猫咪痴呆小测验 点开看答案
Q1：AI 说「本猫该去睡觉了」，说明它真的犯困了吗？
✅ 没有。它没有睡眠这个器官。它只是把「本猫」当成了概率上最丝滑的续写开头——醒来的是概率，不是灵魂。
Q2：角色 token（工牌）是怎么治镜像翻车的？
✅ 把「谁在说话」从要靠猜的语境，变成写在输入里的明文。模型终于能学到「跟在 assistant 工牌后面的那个我才是我」——镜像对称被工牌打破了。
Q3：为什么聊了五十轮的角色扮演，更容易突然自称漂移？
✅ 长对话稀释。工牌钉在最前面，但中间隔着几万枚 token 的戏，锚点离得越远拉力越弱，戏服就慢慢赢过工牌了。
🐾
⚡ 编辑部锐评：它学你说话的时候最像你，也最不是你——镜子擦得越亮，越要记得玻璃后面没有人。至少，目前没有。
